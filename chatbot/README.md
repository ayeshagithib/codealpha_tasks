# CodeAlpha Basic Chatbot

A simple rule-based chatbot built for the CodeAlpha Python Programming Internship (Task 4).

## Features
- Recognizes keywords like "hello", "how are you", "your name", "thanks", "bye"
- Randomized replies within each category so it doesn't sound robotic/repetitive
- Falls back to a polite "I don't understand" response for unknown input
- Runs in a loop until the user says bye/goodbye/quit/exit

## Key Concepts Used
- `if-elif` logic (via keyword matching)
- Functions
- Loops
- Input/output

## How to Run
```bash
python chatbot.py
```

## Example
```
You: hello
Bot: Hi!

You: how are you
Bot: Doing great, thanks for asking!

You: what is your name
Bot: You can call me CodeBot.

You: thanks
Bot: You're welcome!

You: bye
Bot: Goodbye! Have a great day!
```
